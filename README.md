## 一、 项目简介

本项目针对经典 MNIST 数据集（70,000 张 28×28 单通道灰度图像，10 个离散数字类别），严格遵循深度学习研发规范，从零独立搭建并完成了端到端的手写数字分类系统。

项目完整实现了**数据加载与工程优化**、**模型架构设计（MLP vs CNN）**、**训练监控与过拟合严格识别**、**混淆矩阵与错误样本归因**、**多超参数对比消融实验**，以及结合进阶知识点（BatchNorm、Dropout、数据增强、余弦退火学习率调度）的**进阶模型优化**。

## 四、 快速复现指南 (Quick Start)

所有核心功能均支持独立一键运行，实验图表统一输出到 `实验图表输出/` 目录（脚本会自动创建），权重保存在仓库根目录：

### 1. 数据探索与分布可视化 (任务 1)
```bash
python dataset.py
```
> 输出：`实验图表输出/task1_sample_16.png` 与 `实验图表输出/task1_class_distribution.png`。

### 2. 基线模型 100 轮训练与过拟合识别 (任务 2 & 3)
```bash
python train.py
```
> 输出：保存基线权重 `model.pth`，并生成包含 Train/Val 双线对照的 `实验图表输出/training_curves.png`。

### 3. 测试集评估、混淆矩阵与错误样本分析 (任务 4)
```bash
python evaluate.py
```
> 输出：打印测试集整体准确率及 Top 5 混淆排位，保存 `实验图表输出/confusion_matrix.png` 与 `实验图表输出/task4_error_samples.png`。

### 4. 超参数控制变量对比实验 (任务 5)
```bash
python compare.py
```
> 输出：运行 5 组严格控制变量实验（MLP vs CNN、Adam vs SGD、lr 0.1 vs 0.01 vs 0.001），保存 `实验图表输出/task5_comparison_charts.png`，并打印/存档结果表格 `实验图表输出/task5_results_table.txt`。

### 5. 进阶改进版模型训练与平滑收敛 (进阶亮点)
```bash
python improve.py
```
> 输出：执行 30 轮结合余弦退火、BatchNorm、Dropout 与数据增强的进阶训练，保存最优检查点 `best_improved_model.pth` 与平滑收敛曲线 `实验图表输出/improved_training_curves.png`。

## 五、 核心实验成果与指标对照

在 10,000 张独立测试集上的最终评估表现如下：

| 模型版本 | 核心技术要点 | 参数量规模 | 测试集准确率 | 错误样本数 | 相对错误下降幅度 |
| :--- | :--- | :---: | :---: | :---: | :---: |
| **MLP 基线** | 漏斗形全连接降维 (784-128-64-10) | 109,386 | **97.35%** | 265 / 10,000 | 基准 |
| **标准 CNN** | 卷积池化特征提取 (3×3 + 5×5) | 118,350 | **99.09%** | 91 / 10,000 | 较 MLP 下降 **65.7%** |
| **Improved CNN** | **BN + Dropout(0.2) + 数据增强 + 余弦退火** | 118,446 | **99.38%** | **62 / 10,000** | **较标准 CNN 再降 31.9%**<br>(较 MLP 暴降 **76.6%**) |

### 控制变量对比实验 (任务 5, 10 Epochs 验证集 10000 张)

| 组别 | 模型 | 优化器 | 学习率 | 最终验证准确率 | 最佳验证准确率 |
| :---: | :---: | :---: | :---: | :---: | :---: |
| 1 | MLP | Adam | 0.001 | 97.31% | 97.31% |
| 2 | CNN | Adam | 0.001 | 98.78% | 98.90% |
| 3 | CNN | SGD | 0.01 | 98.71% | 98.72% |
| 4 | CNN | SGD | 0.1 | 97.56% | 98.40% |
| 5 | CNN | SGD | 0.001 | 97.61% | 97.61% |

> 与实验结论对应：Adam 收敛快且平稳；SGD 中 0.01 表现最佳，0.1 全程震荡（最佳与最终相差 0.84 个百分点），0.001 收敛偏慢；架构维度 CNN 全面领先 MLP。逐轮曲线见 `实验图表输出/task5_comparison_charts.png`。

## 六、 关键实验发现与理论归因

1. **归纳偏置决定特征表征上限**：
   在参数量严格对齐（同为 ~11 万）的前提下，CNN 测试错误数由 265 骤降至 91。这无可辩驳地证明：CNN 依靠局部感受野（Local Receptive Fields）和权重共享（Weight Sharing），天生具备二维空间几何提取与平移不变性，全面超越缺乏空间先验的 MLP 全局模板匹配。
2. **过拟合现象的严格识别**：
   在基线 CNN 训练至第 40 轮后，训练损失降至 0.0000（训练准确率达 100%），而验证损失从 0.0542 逐渐反弹至 0.1398（典型的“U型反弹 / 翘尾”现象），形成了约 0.85% 的泛化剪刀差。这清晰证明了未加正则化和退火策略的基线网络在中后期出现了轻度死记硬背。
3. **余弦退火与正则化协同消除震荡**：
   Adam 优化器的自适应仅平衡不同参数维度更新尺度，无法在时间维度上将全局步长衰减至零。进阶模型引入 `CosineAnnealingLR` 平滑衰减全局学习率，配合 `Dropout(0.2)` 与 `BatchNorm`，使验证损失全程压制在 0.043 且无任何反弹，彻底消除后期震荡，准确率跨越式提升至 99.38%。
4. **错误样本的书写歧义归因**：
   混淆矩阵与错误分析表明，模型误判高度集中于 $2 \leftrightarrow 7$、$9 \leftrightarrow 4$、$4 \leftrightarrow 9$ 与 $5 \leftrightarrow 3$ 等拓扑近邻数字。此类样本普遍存在连笔、笔锋断裂或闭环形态异化，属于数据本身的标注多义性，而非模型结构失效。

## 七、 附加交互演示 (web/)

纯前端交互网页，用于答辩现场展示，**双击 `web/index.html` 即可打开**（依赖已全部本地化，断网可用）：

1. **模型积木与动态代码**：拖拽/增删网络层实时生成带形状注释的 PyTorch 代码。每层输入由上一层输出自动推导（首层固定接收 1×28×28 灰度图），非法结构（卷积放到展平之后、特征图过小仍池化、输出层不是 Linear→10）会被实时拦截；支持卷积、池化（Max/Avg）、BatchNorm、全连接独立积木与数据增强开关。
2. **手写数字实时识别**：画板手写 0~9，浏览器端用 JS 复现完整 CNN 前向传播（输入自动 28×28 质心居中）。默认加载 `model.pth` 导出的权重；**支持拖拽上传 `.pth` 热更换模型**（如拖入 `best_improved_model.pth` 会自动识别并应用其中的 BatchNorm 层），解析失败会明确报错且不影响当前模型。

> 重新训练模型后，在 `web/` 目录运行 `python export_weights.py` 即可同步更新网页默认权重（脚本会用 numpy 复现前向传播并与 PyTorch 比对验证）。
